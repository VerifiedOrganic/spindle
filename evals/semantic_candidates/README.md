# Semantic candidate snapshots

Generated by `python3 evals/semantic_candidate_snapshots.py --binary <spindle-mcp>`.

Each file records deterministic P2 candidate-selection metadata for one public
continuity suite and variant: scene ordinals, candidate counts, families, check
types, canon table names, evidence origins, and cap omissions. Prose, record ids,
canon ids, and evidence quotes are intentionally omitted, keeping the snapshots
stable and privacy-safe. Regenerate and review these files whenever candidate
selection, ranking, caps, or the public corpora change.
